# 本地与线上部署排错

## 一、配置密钥（本地 PowerShell）

临时设置：
```powershell
$env:WECHAT_MINI_PROGRAM_APP_ID="小程序 AppID"
$env:WECHAT_MINI_PROGRAM_APP_SECRET="小程序 AppSecret"
$env:DB_PASSWORD="数据库密码"
```

生成 JWT 密钥：
```powershell
$bytes = New-Object byte[] 32
$rng = [System.Security.Cryptography.RandomNumberGenerator]::Create()
$rng.GetBytes($bytes)
[Convert]::ToBase64String($bytes)
$rng.Dispose()
```
密钥生成后保存到服务器配置；不要写入前端或提交 Git。

## 二、后端打包（本地 PowerShell）

```powershell
cd E:\\ai_mall\\backend
mvn "-Dmaven.repo.local=E:\\ai_mall\\.m2\\repository" clean package -DskipTests
```
生成文件：`E:\\ai_mall\\backend\\target\\mall-backend-1.0.0.jar`。
`compile` 只编译，不会重新生成可上传的 jar；发布要使用 `package`。

## 三、服务器配置文件

文件位置：`/www/wwwroot/mymall/backend/backend.env`。
每行一个变量，等号两边不要有空格或引号：
```text
DB_URL=jdbc:mysql://127.0.0.1:3306/数据库名?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
DB_USERNAME=mall
DB_PASSWORD=数据库密码
SERVER_PORT=8080
JWT_SECRET=随机密钥
WECHAT_MINI_PROGRAM_APP_ID=小程序AppID
WECHAT_MINI_PROGRAM_APP_SECRET=小程序AppSecret
```
在宝塔 Java 项目中选择“从文件加载”并绑定此文件，保存后重启项目。

## 四、检查 Windows 换行符（服务器 Linux）

```bash
file /www/wwwroot/mymall/backend/backend.env
```
若显示 `CRLF line terminators`，执行：
```bash
sed -i 's/\r$//' /www/wwwroot/mymall/backend/backend.env
```
检查原始长度（不自动去掉换行符）：
```bash
while IFS= read -r line; do
  key="${line%%=*}"
  value="${line#*=}"
  printf '%s: %s\n' "$key" "${#value}"
done < /www/wwwroot/mymall/backend/backend.env
```

## 五、查看线上日志

日志文件：`/www/wwwroot/mymall/backend/logs/mall-backend.log`。
实时查看：
```bash
tail -f -n 500 /www/wwwroot/mymall/backend/logs/mall-backend.log
```
重点搜索：
```text
ERROR
Caused by
Access denied
未处理请求异常
```

## 六、端口和进程检查

本地 PowerShell：
```powershell
netstat -ano | findstr :8080
```
服务器 Linux：
```bash
ss -lntp | grep 8080
```
只有确认进程和 PID 后，才考虑结束进程。不要随意执行强制删除或结束命令。

## 七、常见判断

- `Access denied`：数据库用户名或密码不正确，或配置文件未加载。
- `Unknown database`：数据库名不正确。
- `Communications link failure`：数据库地址或端口不通。
- 浏览器能访问、手机不能访问：通常是 HTTPS 或微信合法域名问题。
- 日志只有启动信息：可能查看了错误文件，或线上运行的不是最新 jar。
