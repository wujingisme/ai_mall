# Navicat 连接线上数据库

## 1. 建立 SSH 隧道

在本地 PowerShell 执行：

```powershell
ssh -L 13306:127.0.0.1:3306 root@服务器IP
例如ssh -L 13306:127.0.0.1:3306 root@124.221.241.24
```

首次连接输入 `yes`，再输入服务器 SSH 密码。看到服务器命令提示符后不要关闭窗口。

## 2. Navicat 配置

```text
主机：127.0.0.1
端口：13306
用户名：数据库用户名（例如 mall）
密码：数据库密码
数据库：目标数据库
```

Navicat 的 SSH 选项不要勾选，因为隧道已经由 PowerShell 建立。


方案二
在 Navicat连接属性中：
1. 打开连接属性。
2. “常规”页面设置：
主机：127.0.0.1
端口：3306
用户名：mall
3. 打开“SSH”页面。
4. 勾选“使用SSH隧道”。
5. 设置：
SSH主机：124.221.241.24
SSH端口：22
SSH用户名：root
SSH密码：服务器SSH密码

## 3. 常见问题

- 不要填写服务器公网 IP 和 3306 端口；使用 `127.0.0.1:13306`。
- PowerShell 隧道窗口关闭后，Navicat 连接会断开。
- 服务器 SSH 密码和 MySQL 数据库密码不是同一个密码。
- `Access denied` 表示数据库用户名或密码不正确。
