# AI Mall workspace instructions

Before inspecting or changing this repository, read `PROJECT_MEMORY.md` in the repository root. Treat it as the shared cross-task project memory for `frontend`, `admin`, `backend`, `api`, and `database`.

After every material code, configuration, API, database, build, or workflow change:

1. Update `PROJECT_MEMORY.md` in the same task.
2. Keep the current architecture, API/auth behavior, run commands, and known issues accurate.
3. Add a concise entry to **Change log** with the date, affected modules, what changed, and verification performed.
4. Remove or correct stale statements instead of accumulating contradictory notes.

Never put passwords, tokens, private keys, personal data, or machine-specific secrets in the memory file. Do not use the memory as a substitute for checking the exact files involved in a risky change; use it to locate and understand the relevant code quickly.
